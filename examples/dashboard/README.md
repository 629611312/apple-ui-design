# Dashboard example

This example demonstrates a calm operational overview:

- a persistent navigation region;
- three decision-driving metrics;
- one quiet trend visualization;
- visible scope and date controls;
- an exact-value table below the visual summary;
- light/dark tokens and a compact responsive fallback.

Open [`index.html`](index.html) directly in a browser. It is dependency-free and intentionally small; in a real project, replace the static values with the existing data layer and keep the same information hierarchy.

Before/after test:

- Before: equal-weight cards for every value, bright gradients, a chart without units, and filters hidden behind a mystery icon.
- After: fewer metrics, explicit scope, a readable chart with an exact table, neutral surfaces, and filters that remain discoverable.
