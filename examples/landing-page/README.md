# Landing page example

Use this brief to test content-first marketing composition.

- One sentence that names the product outcome, not an abstract feature.
- One primary action and one quieter secondary action.
- A proof section with three concrete facts, not three decorative cards.
- A product image or focused interface preview that earns its space.
- A compact responsive navigation that keeps the primary action visible.
- No purple AI gradient, fake glass dashboard, or viewport-height trap on mobile.

Acceptance test: remove every shadow, gradient, and animation. The page should still have a clear story and obvious next step.
