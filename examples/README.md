# Examples

These examples are deliberately small. They demonstrate the design decisions the skill should make before a real product supplies its own data, routes, and components.

- [Dashboard](dashboard/README.md): overview, metrics, trend, filters, and dense table behavior.
- [Landing page](landing-page/README.md): content hierarchy, one primary action, and responsive composition.
- [Admin panel](admin-panel/README.md): operational table, filters, bulk actions, and detail editing.

The examples are briefs rather than a UI framework. Copy the brief into an AI coding agent, point it at the target project, and ask it to implement the design using the project's existing stack.
