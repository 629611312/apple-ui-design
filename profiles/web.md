# Web profile

Use for product sites, marketing pages, editorial experiences, account areas, and general responsive web apps that aren't primarily dashboards or admin tools.

## Character

- Content-led, spacious, direct, and quiet.
- Strong type hierarchy with a restrained palette.
- Large visual moments only when the content earns them.
- Product identity remains visible; Apple influence appears in clarity and interaction quality, not copied chrome.

## Structure

- Use a compact top navigation for a small site; introduce a sidebar only for persistent application hierarchy.
- Keep page width and reading measure intentional. Allow media and product demonstrations to break wider when useful.
- Build sections from headings, text, media, and whitespace before adding cards.
- Use one clear primary call to action per region and keep secondary actions visibly secondary.
- Keep footer and utility navigation easy to scan; don't hide essential product information behind decorative interaction.

## Components

- Prefer semantic HTML and native controls, enhanced with CSS.
- Use cards for self-contained products, plans, articles, or actions—not as the default section container.
- Use sticky or translucent navigation only when it improves orientation; provide a solid background once content would reduce legibility.
- Use dialogs for brief blocking decisions, sheets for focused workflows, and popovers for anchored lightweight choices.
- Keep search scope and result behavior obvious.

## Responsive behavior

- Start from content order. Ensure the compact layout remains complete before introducing multi-column composition.
- Collapse navigation without hiding the current location or primary action.
- Reflow side-by-side storytelling into a logical sequence; don't alternate visual order in a way that harms reading order.
- Avoid viewport-height hero sections when mobile browser chrome or large text would clip content.
- Respect safe areas for installed web apps and full-screen media.

## Visual defaults

- System font stack unless a licensed brand font is established.
- Neutral canvas and opaque content surfaces; use accent color sparingly.
- Moderate radii that reflect component scale.
- Subtle separators and shadows; one depth cue is usually enough.
- Motion limited to navigation continuity, disclosure, and feedback.

## Quality check

Test without animation, without blur support, at 200% zoom, by keyboard, in both color schemes, and with realistic long content. The experience should still feel intentional.
